# Simon Says Game 

## About the Project

Simon Says is a browser-based memory game developed using HTML, CSS, and JavaScript. The player must remember and repeat a sequence of colored buttons. The sequence becomes longer as the player progresses through the game.

## Features

- Four colored buttons for gameplay.
- Keyboard interaction to start the game.
- Random color sequence generation.
- Score tracking as the player progresses.
- Game-over message when an incorrect sequence is entered.
- Option to restart the game.

## Technologies Used

- **HTML5** – Structure of the game.
- **CSS3** – Styling and layout of the colored buttons.
- **JavaScript** – Game logic, event handling, and score management.
- **DOM Manipulation** – Updating game messages and interface elements.

## How to Run

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser.
4. Press any key to start the game.
5. Remember the displayed color sequence and repeat it by clicking the colored buttons.
6. Continue playing to increase your score.
